# openGemini-rs 文档

## 项目概述

openGemini-rs 是一个用 Rust 编写的云原生分布式时序数据库存储引擎，旨在提供高性能、高可靠性的时间序列数据存储和查询能力。

**目标用户**: IoT 设备监控、运维监控系统、时序数据分析场景的开发者

**核心价值**:
- 高性能列式存储，支持 15:1+ 压缩比
- LSM-tree 结构优化写入性能
- TSSP 分段文件格式支持海量时序数据
- 模块化设计，便于集成和扩展

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 编程语言 | Rust | 内存安全、高性能、零成本抽象 |
| 存储格式 | TSSP | openGemini 原生格式，列式压缩 |
| 压缩算法 | snappy/zstd/lz4 | 高压缩比选择 |
| 索引 | Roaring Bitmap | 高效的位图索引 |
| 构建工具 | Cargo | Rust 官方构建工具 |

## 核心功能

### 存储引擎
- **目的**: 提供高性能的时序数据存储
- **描述**: LSM-tree 结构的存储引擎，支持内存表、预写日志和 TSSP 文件

### 内存表 (MemTable)
- **目的**: 缓冲写入数据
- **描述**: 内存中的有序数据结构，写满后刷盘

### 预写日志 (WAL)
- **目的**: 保证数据持久性
- **描述**: Write-Ahead Log，支持崩溃恢复

### TSSP 文件
- **目的**: 列式存储时序数据
- **描述**: Time-Series Segmented Partition，分段列式存储

### 压缩模块
- **目的**: 减少存储空间
- **描述**: 支持多种压缩算法（snappy、zstd、lz4）
